# たびベル貯金（PWA版）

このフォルダーは、元のHTMLをホーム画面からアプリのように起動できるPWAにしたものです。

## 使い方（Android / Pixel）

1. このフォルダー一式を、HTTPS対応のWebサーバーにアップロードします（例：GitHub Pagesなど）。
2. 公開されたURLをChromeで開きます。
3. Chrome右上の「︙」→「アプリをインストール」または「ホーム画面に追加」を選びます。
4. ホーム画面の「たびベル貯金」アイコンから起動します。

## 大事な点

- PWAのインストールにはHTTPSでの公開が必要です。HTMLファイルを端末で直接開くだけではインストールできません。
- 貯金残高・履歴・設定は、これまでどおり端末内のブラウザー保存領域（localStorage）に保存されます。別端末との自動同期はありません。
- 初回表示ではTailwind CSSとWebフォントの読み込みにインターネット接続が必要です。アプリ本体はService Workerでキャッシュします。
- 元のアプリの機能・デザイン・データキーは維持しています。
